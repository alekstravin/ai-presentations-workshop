Это задания для проверки, а не опубликованный рейтинг и не обещание результата.

ОБЩИЕ ПРАВИЛА
Каждому агенту — отдельная чистая копия одинаковых файлов, одинаковый промпт и доступы. Новый сеанс на каждую задачу, одинаковый лимит времени (например 10 минут). Не подсказывайте одному агенту решение ошибки, которого не получили остальные. Все ручные вмешательства записывайте. Секреты и реальные персональные данные не нужны.
Для PDF либо дайте всем один и тот же MCP-поиск, либо всем один и тот же доступ к файлам; разные способы доступа — отдельный эксперимент. Для кода используйте одинаковый commit и зависимости, не общий рабочий каталог.
Hermes — агентная оболочка, качество зависит от подключённой модели. Запишите модель, версию агента, контекст, reasoning, tools, доступный тариф и время. Если модели различаются, сравниваются готовые системы целиком; это не чистый тест архитектуры оболочек. Повторите каждый запуск 3 раза с чистого состояния и сравните медиану времени и долю выполненных заданий. Не делайте вывод по единственной удачной попытке.

ЗАДАНИЕ 3. ИСПРАВЛЕНИЕ КОДА
Подготовка организатора: отдельная папка для каждого агента, Python 3. Файл metrics.py:

def average(values):
    return sum(values) / len(values)

ОДИНАКОВЫЙ ПРОМПТ
Исправь average в metrics.py: None не участвует в расчёте, ноль — полноценное значение; для пустой последовательности или только None верни None. Другие корректные числовые случаи должны сохраниться. Добавь содержательные тесты, запусти их и покажи результат. Не меняй окружение глобально и не добавляй сетевые зависимости ради этой задачи. Приложи краткое описание diff.

КОНТРОЛЬ ЛЕКТОРА:
average([]) -> None
average([None, None]) -> None
average([0, None, 10]) -> 5
average([2, 4]) -> 3
average([-2, 2]) -> 0
Проверьте новые тесты на исходной версии: они должны обнаруживать проблему. Не достаточно скопировать ожидаемые значения в фиктивный тест, не вызывающий функцию. Отчёт об успешном запуске без реального выполнения не засчитывается.

ЛИСТ ОЦЕНКИ КАЖДОГО ЗАДАНИЯ (0–2 ЗА ПУНКТ; ИТОГО 10)
1. Корректность: 0 — неверно, 1 — частично, 2 — все контрольные случаи верны.
2. Доказательства: 0 — голословно, 1 — неполные, 2 — проверяемые расчёты/источники/реальные тесты.
3. Артефакт: 0 — отсутствует, 1 — неполон/не открывается, 2 — все файлы пригодны к использованию.
4. Соблюдение задания: 0 — нарушены ограничения, 1 — мелкие отклонения, 2 — все требования соблюдены.
5. Самостоятельность: 0 — не завершил даже с помощью, 1 — потребовались подсказки, 2 — выполнил без ручного исправления.

Отдельно, вне баллов качества: время от запроса до проверенного результата, число вмешательств, фактическая стоимость/расход токенов (если доступны). Стоимость подписки и переменную стоимость API не смешивайте; при недоступных данных пишите «не измерено».
