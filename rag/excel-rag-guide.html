EXCEL → UNSLOTH DESKTOP
Практическое руководство на примере
экспорта СПГ
Два сценария: (1) поиск по таблице через RAG; (2) точный анализ таблицы через Python и
локальную языковую модель. В комплекте: XLSX и подготовленный TXT для RAG.
Что находится в учебной таблице
Данные за 2024 год: крупнейшие экспортёры СПГ, регион, экспорт в млн тонн и доля мирового
объёма. Мировой итог — 405,8 млн т. Значения округлены; «Прочие страны» — агрегированная
категория. Источник и ограничения указаны в Excel на листе «О данных».
Сценарий А. Поиск по Excel через RAG — без программирования
1. Откройте файл LNG_exports_2024_GIIGNL_training.xlsx и ознакомьтесь с колонками и листом
«О данных».
2. Для RAG используйте приложенный LNG_exports_2024_for_RAG.txt: каждая строка Excel
преобразована в отдельную запись с названиями полей. Это надёжнее, чем рассчитывать на
прямую поддержку XLSX.
3. Запустите Unsloth Desktop, откройте интерфейс базы знаний / RAG (названия кнопок зависят
от версии). Создайте базу или выберите существующую.
4. Добавьте TXT в базу знаний, дождитесь завершения обработки/индексации. Если появилось
сообщение об ошибке, сохраните его текст.
5. Откройте чат с моделью, убедитесь, что нужная база знаний подключена к чату, и задайте
тестовый вопрос.
6. Проверьте ответ по исходному Excel: найденная запись должна содержать точные значения
и страну.
 Примеры запросов: «Сколько СПГ экспортировала Россия в 2024 году?», «Какой объём экспорта у
Катара?», «Покажи данные для Малайзии и назови источник».
Ограничение: RAG ищет релевантные фрагменты, а не гарантированно просматривает все
строки. Запросы «посчитай сумму», «ранжируй все страны», «вычисли среднее» лучше
выполнять через Excel или Python.
Сценарий Б. Точные вычисления: Excel → Python → модель
1. Сохраните XLSX в доступной папке компьютера.
2. Установите Python и библиотеки pandas и openpyxl в той среде, где будет выполняться код.
3. Запустите код ниже локально: он прочитает Excel, исключит строку «ИТОГО» и агрегат
«Прочие страны» для рейтинга отдельных государств.
4. Передайте полученные результаты модели Unsloth в чат для интерпретации; либо
подключите модель к внешнему Python-скрипту через совместимый API, если он доступен в
вашей версии.


5. Не считайте, что загрузка XLSX в RAG автоматически даёт модели право запускать Python.
Для исполнения кода требуется отдельный инструмент/интеграция.
 pip install pandas openpyxl
import pandas as pd
df = pd.read_excel("LNG_exports_2024_GIIGNL_training.xlsx", sheet_name="Экспорт СПГ 2024")
countries = df[~df["Страна / группа"].isin(["ИТОГО", "Прочие страны"])]
print(countries.nlargest(5, "Экспорт, млн т")[["Страна / группа", "Экспорт, млн т"]])
print("Экспорт России:", countries.loc[countries["Страна / группа"] == "Россия", "Экспорт, млн т"].iloc[0])
Вопрос модели после выполнения расчётов: «На основании приведённых результатов объясни
структуру экспорта СПГ и назови три наблюдения. Не пересчитывай цифры самостоятельно».
