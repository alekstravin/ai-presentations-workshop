Unsloth RAG → Telegram
Один блок для терминала

Для macOS, Linux и Windows с Python 3.10+. Выберите блок для своей системы. Запустите Unsloth, загрузите модель и проиндексируйте документы. Скопируйте весь блок, вставьте в терминал и нажмите Enter.

Скрипт запросит токены скрытым вводом, предложит выбрать модель и базу знаний, создаст отдельную папку и запустит бота. Подходит и для нового бота с другой базой.

macOS / Linux · Terminal

Скачать .sh

Windows · PowerShell

Установите Python 3.10+ с официального сайта Python. Проверьте py -3 --version. Откройте PowerShell, скопируйте блок ниже и выполните его. Менять ExecutionPolicy не требуется: блок можно вставить прямо в консоль.

Скачать .ps1

Для повторного запуска из папки бота: & ".\.venv\Scripts\python.exe" ".\bot.py". Полный путь скрипт выведет после настройки. Остановка: Ctrl+C.

При запросе токена символы не отображаются — это нормально. Получить Telegram-токен: @BotFather → /newbot. Ключ Unsloth: Settings → API.

Бот работает, пока открыт терминал и доступен Unsloth. Остановка: Ctrl+C. Команду повторного запуска скрипт напечатает. Для одного Telegram-токена запускайте один процесс polling.

Адрес 127.0.0.1 подходит, если бот и Unsloth работают на одном компьютере. RAG API зависит от версии Studio. Если выбранная модель выгружена и другие модели не заняты, бот загрузит её при первом вопросе. Каждый ответ использует выбранную базу; история диалога не сохраняется.
