# RAG — Клуб ИИИИ

Откройте index.html в браузере. Это автономная презентация: шрифты, реальные скриншоты и полный код встроены. Интернет нужен для внешних ссылок.

12 слайдов, светлая / тёмная тема. Стрелки — листать; T — тема; F — полный экран; E — правка текста на время просмотра.

Кнопки Python открывают весь код в диалоге или отдельном окне, копируют и скачивают rag_template.py. code.html — дополнительная самостоятельная страница кода.

unsloth_rag_setup_slide.html — отдельная светлая памятка 16:9 по предоставленным вами техническим деталям.

Числовые настройки retrieval — стартовые профили из практического опыта пользователя, не гарантированно оптимальные значения. Путь Knowledge Base соответствует присланной версии интерфейса. Снимки из официальной документации и PR разработчиков снабжены ссылками; сборки могут отличаться.

Python: проверены синтаксис и сквозной сценарий PDF/TXT → индекс → поиск → chat через тестовый локальный HTTP-сервер. Настоящие веса моделей в этой проверке не запускались. Для работы установите Ollama, numpy, pypdf и модели по инструкции в начале кода.
