# Сохранённый профиль восстановления СПГ

Это код фактически проверенной локальной конфигурации Mac / Unsloth 0.1.900-beta,
а не универсальный установщик RAG. На настроенном Mac файлы уже установлены;
скачивание архива само по себе ничего не запускает и не изменяет.

Не входят в архив: PDF, индексы, базы SQLite, модели GGUF, токены, .env и журналы.
Новая база должна уже существовать. Её ID записан в lng_page_search.py, bot.py,
new-kb.json и verified-settings.json. Чат указан в ready-thread.json.
На другом Mac эти ID необходимо заменить, переиндексировать собственные документы,
установить и проверить эмбеддер. Само копирование папок базу не создаёт.

Для установленного Desktop ожидается его Python 3.13 в ~/.unsloth/studio/unsloth_studio/bin/python.
Эмбеддер ожидается в ~/.unsloth/studio/models/lng-embedder/paraphrase-multilingual-MiniLM-L12-v2-F16.gguf.
Токенизатор GGUF получен отдельной конверсией; файл модели в архив не включён.

Папки должны лежать рядом: lng-rag-repair-2026-10-05 и testlng-bot.
До запуска start_lng.py полностью завершите Unsloth через Quit Unsloth.
Этот скрипт устанавливает opt-in hook, задаёт env и загружает сохранённый профиль.
apply_profile.py дополнительно применяет настройки сохранённого чата.
Для проверки источников используйте инструкции на опубликованной странице.

Telegram-зависимости: pip install -r testlng-bot/requirements.txt.
Токен хранится локально: скопируйте .env.example в .env, замените placeholder,
ограничьте права chmod 600 .env. Не размещайте .env в GitHub.
bot.py проверяет username TestLNG234421234_bot при запуске.
Для другого бота измените USERNAME и используйте его токен.

Службы launchd на рабочем Mac настроены отдельно, не содержат токенов:
local.club.lng-rag-runtime и local.club.testlng-bot.
RunAtLoad=false: автоматический запуск после входа в macOS не включён.
После обновления Desktop нужно заново проверить hook и совместимость API.
