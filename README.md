# Презентации с агентным ИИ

Интерактивная HTML-презентация для практического мастер-класса о создании презентаций с помощью Gamma, ChatGPT, Codex, HTML и Remotion.

- [Открыть презентацию](https://alekstravin.github.io/ai-presentations-workshop/)
- [Открыть галерею примеров](https://alekstravin.github.io/ai-presentations-workshop/examples/)
- [Скачать светлую PDF-версию](https://alekstravin.github.io/ai-presentations-workshop/ai-presentations-workshop-light.pdf)

Управление: стрелки, Page Up / Page Down, Home / End. Переключатель ☀/☾ меняет светлую и тёмную темы.
